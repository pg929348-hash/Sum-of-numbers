# Sum of Numbers from 1 to 10

This simple Python program calculates the sum of numbers from 1 to 10 using a `for` loop.

## ▶️ How it Works

1.  `a = 0` - Initialize a variable `a` to store the sum.
2.  `for i in range(1, 10+1)` - Loop runs from 1 to 10.
3.  `a = a + i` - In each iteration, add the current number `i` to `a`.
4.  `print(a)` - Finally, print the total sum.

## 💻 Output

```
55
```

## 🚀 How to Run

```bash
python sum.py
```
